# Hosting readiness — LeadAssign (2026-09-14)

Кратко: полноценный бесплатный always-on demo для текущей архитектуры (FastAPI + PuLP + React static) **не рекомендуется** как основной способ передачи задания.

## Сравнение

| Площадка | Backend Python | Frontend | Sleep / cold start | RAM/CPU free | Карта | Риск данных | Оценка |
|----------|----------------|----------|--------------------|--------------|-------|-------------|--------|
| Render | Да | Static из того же сервиса | Sleep ~15 мин без трафика, подъём ~30–60 с | ~0.1 CPU / 512 MB | Для стабильности часто нужна | Demo data OK | Возможно, но UX cold start плохой |
| Railway | Да | Да | Free ~$1 кредита/мес | 0.5 GB / 1 vCPU на Free | Trial без карты, дальше ограничено | Demo data OK | Мало для always-on |
| HF Spaces | Docker | Да | Лимиты; Docker Spaces ужесточены | Зависит от tier | — | Публичный URL | Нецелесообразно |
| Vercel | Нет (serverless JS) | Да | — | — | — | — | Не подходит для PuLP ILP |
| Netlify | Нет | Да | — | — | — | — | Не подходит |
