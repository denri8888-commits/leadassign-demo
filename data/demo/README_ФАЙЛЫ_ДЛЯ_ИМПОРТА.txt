Синтетические файлы для проверки «Импорт данных»
================================================

Как пользоваться
----------------
1. В интерфейсе откройте раздел «Импорт данных».
2. Выберите тип файла: «История» или «Заявки».
3. Нажмите «Выбор файла» и укажите один из файлов из ЭТОЙ папки.

Совет: из корня архива запустите ОТКРЫТЬ_ПАПКУ_DEMO_ДАННЫЕ.bat —
откроется именно эта папка. Браузер по безопасности не может сам
открыть диалог сразу в нужной папке.

Какой файл выбирать
-------------------
Тип «История»:
  - demo_history.csv
  - demo_history.xlsx
  - demo_history_sample_500.csv   (меньший файл, быстрее)
  - demo_history_sample_500.xlsx

Тип «Заявки»:
  - demo_applications.csv
  - demo_applications.xlsx
  - demo_applications_70.csv

Далее: «Показать колонки» → при необходимости поправить сопоставление → «Построить аналитику».

Это синтетические демонстрационные данные, не данные реальной компании.
