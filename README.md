# LeadAssign — распределение заявок для роста ожидаемой валовой маржи

Система **не ищет лучшего менеджера вообще**. Она ищет лучшее назначение конкретной заявки конкретному менеджеру с учётом ожидаемого результата и ограниченной дневной загрузки.

Демо тестового задания: при ~70 заявках и лимите ~50 переговоров выбрать, кого обработать и кому отдать.

> Все цифры в демо — на **синтетических данных**. Это не показатели реальной компании.

Тестовое задание сформулировано на примере мебельной компании. Подход не зависит от конкретного товара и может быть адаптирован к продажам окон, дверей и других продуктов.

## Как передать работодателю

1. **Главный PDF:** `docs/employer_pdf/Ответ_на_тестовое_задание_LeadAssign.pdf`  
2. **Ссылка на онлайн-демо** (Vercel) — после деплоя из GitHub  
3. **Код на GitHub**  
4. **ZIP** как запасной офлайн-вариант: `LeadAssign_Nemetskie_Okna_Bel_FINAL_2026-09-14.zip`

Старые архивы `GermanWindows_*` и `*_FINAL_2026-09-13.zip` не использовать.

## Онлайн-демо (Vercel)

Подготовка уже в репозитории (`vercel.json`, `api/index.py`).

Кратко: GitHub → Import в Vercel → получить ссылку для работодателя.

Подробно: [`docs/VERCEL_DEPLOY.md`](docs/VERCEL_DEPLOY.md)

Первый заход после паузы может занять десятки секунд — так устроен бесплатный serverless.

1. Распаковать архив  
2. Открыть `Быстрый_старт.pdf` или `README_КАК_ЗАПУСКАТЬ.txt`  
3. Дважды кликнуть `ЗАПУСТИТЬ_ДЕМО.bat`

## Запуск для разработчика

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONPATH = (Get-Location).Path
uvicorn app.main:app --reload --port 8000

# другой терминал
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173
