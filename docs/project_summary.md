# Краткий итог проекта

## Что реализовано

- Генератор синтетических данных со сценариями и seed
- Сглаженная конверсия, recency, fallback hierarchy, confidence
- Оценка пар заявка × менеджер и Expected GM
- Greedy + optimal assignment, baselines, capacity analysis, simulation
- FastAPI со схемами ответов и понятными ошибками
- React dashboard: KPI, рекомендации, drawer, менеджеры, heatmap, настройки, импорт, результат дня
- Тесты unit/scenario/API
- Документация: architecture, test answer, demo script, data dictionary

## Допущения

- 5 менеджеров, 70 заявок, capacity 50 (настраивается)
- Гибкие индивидуальные лимиты
- Демо-данные ≠ реальные показатели
- Основной режим — объяснимая статистика

## Сознательно НЕ делалось

- Нейросеть / LLM-чат
- Production CRM, auth, очереди
- Внешние социально-экономические данные
- Автоматический вывод «надо нанимать»
- Использование пола/возраста как критерия

## Ограничения

- Оптимальность при сумме индивидуальных capacity > team capacity достигается через слоты (приближение к MIP)
- Импорт упрощённый
- Эффект на синтетике не равен гарантии на реальных данных
